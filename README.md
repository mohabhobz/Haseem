# حسيم — واجهة المنتج

واجهة React قابلة للتشغيل لمنتج **حسيم**: فوترة إلكترونية ومحاسبة متوافقة مع
هيئة الزكاة والضريبة والجمارك. المشروع ده هو مرجع التصميم — كل شاشة مبنية
على ديزاين سيستم واحد، ومصدر الألوان والمسافات ملف واحد.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # نسخة إنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
```

## قواعد التصميم

**١. مصدر واحد للحقيقة.** كل لون ومسافة وخط في `tokens.css`. مفيش قيمة
مكتوبة بالإيد في `app.css` — لو لقيت واحدة فهي خطأ.

**٢. الوضع الداكن من التوكنز.** `[data-theme="dark"]` بيبدّل نفس أسماء
المتغيرات، فمفيش كومبوننت بيعرف إن فيه ثيمين. وكل قيمة فيه `var()` من
الباليت — مفيش هيكس مكتوب بالإيد، فمستحيل يدخل لون بره البراند.

**٣. الأخضر للأكشن بس.** في الوضع الداكن الأسطح رمادي/أسود محايد،
والأخضر محجوز للأزرار الأساسية والعنصر النشط والرسوم.

**٤. أي حاجة بتتكرر مرتين = كومبوننت.** `DocumentList` هو التطبيق العملي:
نمط «قائمة + فلاتر + حالة + أفعال» بيتكرر في ~١٢ شاشة، مبني مرة واحدة.

**٥. كل كومبوننت بيطبع `data-component="Name"`** على عنصره الجذر — دي
اللي بلاجين فيجما بيمسكها ويحوّلها لكومبوننت بنفس الاسم.

**٦. الأرقام لاتينية دايمًا** حتى في الواجهة العربية، ومعاها رمز الريال
السعودي الرسمي (U+20C1) مرسوم SVG من الخط الرسمي مفتوح المصدر.
